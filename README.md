# LawWare Backend

Preparación de arquitectura para un backend Node.js y TypeScript. `src/` reserva los límites de módulos; aún no hay aplicación ejecutable, dependencias instaladas ni integración Auth0/PostgreSQL. No se han desplegado servicios.

El contrato de integración está en [docs/CONTRATOS_INTEGRACION.md](docs/CONTRATOS_INTEGRACION.md). El SQL v2.1 y sus pruebas son la fuente de verdad en el repositorio hermano [LawWare-database](https://github.com/Jesel8D/LawWare-database); decisiones y estado general están en [LawWare-context](https://github.com/Jesel8D/LawWare-context). Render es el alojamiento previsto y requiere una validación posterior.
